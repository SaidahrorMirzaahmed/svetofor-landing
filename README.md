# Svetofor — landing page

Marketing page for Svetofor, an online practice-test platform for the Uzbek
driving-licence exam (YHQ).

Single self-contained `index.html`, no build step, published with GitHub Pages.

Pricing shown on the page:

| Plan | Price | Unit |
| --- | --- | --- |
| Shaxsiy (individual) | 45 000 so'm / month | per account |
| Haydovchilik maktablari (driving schools) | 30 000 so'm / month | per computer, unlimited students |

The application itself and its question bank live in a separate private
repository — the bank must not be published.
